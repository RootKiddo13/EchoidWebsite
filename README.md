# Echoid Website

Echoid'in Türkçe teknoloji kanalını ve bağlantılarını tanıtan statik web sitesi. Astro ile hazırlanmıştır.

Canlı site: [echoid.pages.dev](https://echoid.pages.dev/)

## Yerel geliştirme

```bash
npm ci
npm run dev
```

`npm run check:data` site verilerini ve türleri kontrol eder. Production build için `npm run build`; build çıktısını yerelde açmak için `npm run preview` kullanın.
