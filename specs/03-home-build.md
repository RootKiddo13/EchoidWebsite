# Spec 03 — Home Build

## Purpose

Implement the approved Echoid home design with the selected hero and a clear path to the channel and its projects.

## Scope

- Use public/assets/brand/echoid-website-hero-selected-v1.png as the approved hero artwork.
- Implement approved decisions and, for open items, the marked preview proposals, including crop and text placement. Treat the result as a review preview.
- Add the Echoid wordmark/header and About trigger if retained in the approved design.
- Show approved Turkish channel identity copy and the confirmed YouTube, GitHub / Projects, X, and Contact destinations.
- Add a simple footer if it is present in the approved design.
- Use custom, visually consistent link glyphs, including a distinct X glyph.
- Use external-link safety attributes for external destination links.
- Keep the page static; do not add a feed or continuous motion.

## Out of scope

- Choosing still-open composition or copy.
- About dialog behavior; Spec 04.
- Responsive/accessibility finish; Spec 05.
- Performance cleanup; Spec 06.

## Acceptance criteria

- The selected asset is the hero and the visual remains consistent with the canonical Echoid identity.
- Rendered layout and copy match approved decisions and explicitly recorded preview proposals; proposals remain drafts pending review.
- YouTube, X, and GitHub open their exact confirmed targets.
- Contact presentation matches the approved decision.
- No RootKiddo-specific logo, copy, yellow palette, mascot overlay, or Gecko effect remains.
- No placeholder text, broken asset, or horizontal overflow.
- Hover feedback is brief and does not make essential information hover-dependent.

## Evidence

- Desktop preview capture.
- Click-through checks for all destinations.
- Hero asset and build checks.
